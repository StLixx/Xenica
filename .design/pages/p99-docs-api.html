PUT /nodes/:id

更新现有节点。支持部分更新（只传需要修改的字段）。返回更新后的完整节点对象。

v2权限：edit限流：60 / 分钟
PUT/api/v2/nodes/:id

路径参数

名称类型必填说明
idUUID v4required节点 ID

请求体

字段类型必填说明
titlestring节点标题 · ≤ 200 字符
contentBlock[]块数组（块编辑器格式）
tagsstring[]标签列表 · ≤ 10 个
position{x, y}画布坐标（用于拖动）
styleNodeStyle颜色、尺寸等样式

请求示例

HTTP / cURLSH
# 更新节点标题与位置
curl -X PUT "https://api.xenica.dev/api/v2/nodes/7a9c-2b4f" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title": "设计原则 v3 · 更新", "position": {"x": 480, "y": 240}}'

响应 · 200 OK

JSONJSON
{
  "id": "7a9c-2b4f",
  "title": "设计原则 v3 · 更新",
  "type": "document",
  "position": { "x": 480, "y": 240 },
  "updated_at": "2026-07-17T10:42:18Z"
}

错误码

状态含义

403无编辑权限
429限流（60 / 分钟）
422字段验证失败
