# Penpot 画板内 HTML 嵌入试样

## 范围批准
2026-10-17 当前对话，用户原话：「那就按这个方案开始，先做一个 Penpot 画板内 HTML embed 的最小可体验版本，能交互、移动缩放，刷新后保留，做好给我体验。」此批准是范围审核，不是成果体验验收。

## 行为与验收
- 新增独立体验文件，在画板中创建 HTML 块；顶部原生更多工具内提供入口，可固定到工具栏，右侧原生属性面板支持在明确选中的 Board 内插入；入口不出现在 Dashboard，不使用独立底部工具条。
- HTML 脚本、按钮、表单在隔离 iframe 内运行；画布编辑与内部交互可明确切换。双击块进入 HTML，不误入原生路径编辑；已有转换路径仍能恢复显示。
- 包含 HTML 的 Board 保留与普通 Board 一样的标题移动和双向调整尺寸；HTML 块自身也支持移动与双向调整尺寸。画布缩放不改变 HTML 的逻辑视口、CSS 媒体查询；原生手柄操作自动退出网页交互，删除及撤销走 Penpot 原生机制。
- 新增块默认适配 Board；已有块可「适配 Board」，保留 HTML/状态并对齐四角，随后随 Board 尺寸拉伸并继承裁剪。
- 刷新及重新打开文件后 HTML、位置和尺寸保留；内置示例状态随文件保存。
- 普通 SVG/PNG 导出允许显示静态占位，不把它冒充可执行 HTML；原型查看支持运行嵌入块。
- 既有账号、设计及多会话 MCP 保留；不迁移数据库、不升级整套 develop。
- 覆盖脚本隔离、错误输入、重复块、刷新、新浏览器、权限、桌面/窄屏和旧文件回归。
- Agent 完成自检和真实部署体验后提供入口；用户体验确认前不合并。

## 实现边界
基于原版 2.18.3 与现网多会话补丁，保存普通矩形及命名空间 plugin-data，扩展画布 HTML 层。源码、可重放补丁和镜像构建方式留在 Xenica；私有凭据和用户设计不入 Git。
任意网页运行状态不自动序列化；内置示例及明确使用状态桥的 HTML 可保存状态。任意第三方 URL 的登录和嵌入策略不在首轮保证内。
