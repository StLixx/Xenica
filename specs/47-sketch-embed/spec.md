# v0.2.2：草图中的真实内容试样

关联：#47。状态：范围已在对话确认并获准开始；#48 继续实施，最终交互成果仍待体验验收。

## 目标与范围

在现有 Excalidraw 上验证 HTML / React Embed，暂不引入 Penpot。用户在同一张草图中编排、体验、批注真实内容，Agent 能从分享数据识别内容来源。结果用于判断现有画布是否适用，不扩展为设计工具迁移。

三个样例：

1. **共享侧栏**：直接使用仓库里的 `PeekAside` 与设计变量，能展开、收起、固定；不能复制组件样式另做一个仿制品。
2. **Xenica 页面**：嵌入本次服务器预览中的真实页面，能操作页面；预览数据与正式数据分离。
3. **网页**：一个允许嵌入的可交互网页或视频，验证点击与滚动。禁止嵌入的网站明确显示无法加载及打开原页入口，不承诺所有网站都可嵌入。

## 行为

- 草图有明确入口添加试样卡片；共享侧栏可直接添加，页面卡片可输入 HTTPS 地址。
- 未进入交互时，卡片属于画布：可选择、拖动、调整尺寸、复制和删除。
- 明确进入卡片交互后，点击、输入和内部滚动交给内容；提供明确退出方式，退出后恢复画布操作。内部操作不能意外移动卡片或在画布画线。
- 卡片随画布平移、缩放；文字和连线可放在卡片旁表达批注。
- 卡片的位置、尺寸、类型、来源与组件标识随草图保存；刷新和重新打开后可恢复。已有草图照常打开，图片附件与原有保存行为继续可用。
- React 样例记录稳定组件标识、仓库文件路径与运行版本；页面样例记录来源 URL。Agent 可从分享的原始场景数据读取这些信息，并据此修改卡片位置、尺寸或来源。
- 内嵌内容继承页面本身的权限；草图分享不赋予访问私有页面的权限，不将登录凭据或分享令牌复制为卡片元数据。
- 画布 PNG 不能代替可交互内容。若导出图不包含内嵌 DOM，则显示可辨认的标题和来源占位，避免把空白卡片当成完整截图。

## 验收

- [ ] **一张混合草图**：三个样例与文字、连线同时可见；侧栏来自真实组件，Xenica 页面可完成一次页面操作。
- [ ] **操作不冲突**：进入卡片后能点击、输入或滚动；退出后能选择、移动卡片与平移画布，不出现误画线或误拖动。
- [ ] **编排可恢复**：三个样例在 50%、100%、200% 缩放下可选择、拖动和调整尺寸；保存后刷新，内容来源、位置和尺寸保持一致。
- [ ] **Agent 可识别**：分享原始数据能区分 React / 页面卡片，定位侧栏源文件及运行版本；一次经授权的场景编辑能反映到草图，且不丢失其他元素。
- [ ] **正常降级**：不可嵌入地址或失效页面有可辨认的提示或打开原页入口；旧草图及图片分享不受影响。
- [ ] **多卡片证据**：在同一预览版本记录 3 张与 20 张混合卡片的首次可交互时间、连续平移/缩放/滚动表现及加载失败情况，指出可接受范围和阻碍。性能数字以实测为准。

交付服务器预览、简短操作说明与上述结果；用户直接体验后决定继续采用、调整交互或重新评估画布。

## 不在本次范围

任意 HTML / React 源码编辑或执行、多 Agent 同时编辑的冲突解决、完整设计系统重构、新知识关系原语、Penpot 接入。试样提供进入真实内容的基础，不宣称已解决设计与代码的长期同步。

构建、测试与截图在已核验的 Infra 开发环境执行；不在 Windows 安装大型工具链。服务器承载临时运行数据，规格、代码与验证结论版本化进 GitHub。
