# MinerU 对照阅读 Web 应用

## 授权

2026-10-17 当前 Codex 会话，用户确认「开始」。已确认 Rust 后端、Infra 现有 PostgreSQL、优先 Desktop 免费 API、本轮不部署识别模型。交互成果待用户实际验收，开始不作产品验收。

## 范围

1. 以安装的 Desktop 0.14.1 为目标，保留版本、SHA256、REA Evidence 和调用链，逐项标识观察、推断与未知。
2. 查清 PDF 段落、图片、表格、公式分块，坐标、阅读顺序、合并、原文与 Markdown/JSON 双向定位、高亮、滚动联动、复制收藏和导出。
3. 核实 Desktop 鉴权生命周期与个人 API Token 差异，优先复用现有远程解析服务；凭据不进客户端、日志或公开仓库。
4. 独立 Rust Web 后端和现有 PG 的独立业务库/受限角色；上传、任务、结果、块、收藏与阅读状态持久化。
5. 在 mineru.truebigsand.top 提供 HTTPS 和私人访问，正常/异常/权限/刷新/重启及桌面窄屏真实自检。
6. 文档、源码、部署、备份恢复和脱敏证据进入 GitHub，原始第三方包和私人原书仅私有保留。

## 检查清单

- [ ] 安装包身份与 REA 证据完整。
- [ ] 分块结构、坐标与跨页合并映射有原始依据。
- [ ] 关键 UX 经真实运行核对，静态推断不冒充执行。
- [ ] 免费 API 鉴权及真实上传到完成链路验证。
- [ ] Rust/PG 持久化与权限隔离。
- [ ] PDF/Markdown/JSON 双向选择和定位。
- [ ] 桌面窄屏、异常、刷新和重启通过。
- [ ] 备份与隔离恢复、部署身份和维护入口。
- [ ] 全部必需工程检查。
- [ ] 用户实际体验确认。

## 保留与边界

REA 原始包/全量证据在 Infra 私有研究目录；公开仓库保存摘要、脱敏结论和重建入口。不训练或自托管识别模型。本轮独立应用并凝练 Xenica UX，不扩展主工作台。
