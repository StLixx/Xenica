# v0.2.5 开发与交付体系

用户于 2026-10-11 在对话确认并要求开始。范围不需再次审批；交互成果完成后实际体验验收。

- 唯一持久开发画板集中组件、Features 和不同版本页面；PR 预览只提供运行内容，关闭预览不删除设计档案。
- 保留原始表达，记录确认决策并关联实现、历史和体验证据；新 Agent 从仓库入口能找到这些事实。
- 产品验收在对话完成，由系统记录到确定的交付候选；候选绑定源码、构建产物、部署和检查。用户不必访问 PR 或学习命令。
- Scope 确认不是成果验收。人工体验判断不能绕过工程检查；非交互成果由机器验证。
- 旧候选、旧验收、失效检查、缺失检查、主线漂移和规则漂移均不能放行；门禁本身有负向回归。
- Excalidraw 原生交互与扩展统一；必要源码改造、上游版本和测试在同一仓库维护，可从干净环境复现。
- Windows 只做轻量编辑与 SSH，所有构建、编译与测试在 Infra。保留尚未通过体验验收的 PR48/51/53。

## 验证

门禁负向测试、架构与上下文完整性检查、既有端到端回归；画板关闭预览后仍持久，版本入口与实际运行产物一致，设计原文和关联可读取。用户只体验整体画板与交互，不读代码。
