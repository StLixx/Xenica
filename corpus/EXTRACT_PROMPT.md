# Agent Prompt: 提炼探索性闲聊历史 → Corpus 文件

## 任务

将 `C:\dev\Commader\.chat_history\key_sessions\03_探索性闲聊.md`（约 9000 行）按话题拆分，提炼为多个独立的 corpus 摘要文件。

## 必读

- 输入文件：`C:\dev\Commader\.chat_history\key_sessions\03_探索性闲聊.md`
- 输出目录：`C:\dev\Xenica\corpus\exploratory\`
- 参考格式：`C:\dev\Xenica\corpus\exploratory\2026-02-15_知识管理工具演化与技术选型.md`

## 输入文件结构

文件是完整的对话记录，格式：
```
## 👤 User [序号]
用户发言

### 🤖 Response
AI 回复（可能含 thinking、tool calls）
```

## 工作方式

**文件太大无法一次读取。** 必须分段处理：

1. 先读前 200 行，了解整体结构
2. 每次读 500 行（用 offset + limit），提取该段的话题和洞察
3. 跨段话题合并到同一输出文件
4. 全部读完后，整理输出

## 输出格式

每个输出文件 = 一个话题集群，命名：`{日期}_{话题关键词}.md`

```yaml
---
type: session_digest
created: {对话发生的日期，从内容推断}
source: 03_探索性闲聊
schema_version: 1
topics: [话题标签1, 话题标签2]
---
```

正文结构：
- `## 核心洞察`：该话题下的关键认知（每条 1-2 句话，原子化）
- `## 讨论脉络`：对话是怎么聊到这个话题的（3-5 句概括）
- `## 跨域连接`：该话题与其他话题的关联（如果有）
- `## 原始引用`：保留 2-3 句用户最精彩的原话（带 User [序号] 标注）

## 提炼原则

1. **提炼不是摘要**：不要概括"用户说了什么"，而是提取"用户得出了什么认知"
2. **保留用户原话**：精彩的表述原样保留，AI 的回复只保留被用户确认的部分
3. **标注不确定性**：用户表达犹豫或探索中的想法，标注 `[探索中]`
4. **不丢弃个人经历**：用户提到的亲身经历（高一地理错题、Obsidian 经历等）是高价值数据
5. **跨话题同构要标出**：如果不同话题之间有结构相似性，在"跨域连接"中标注
