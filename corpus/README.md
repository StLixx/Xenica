# Xenica Corpus 文件夹

**此文件夹用于存放 Xenica 的初始语料和探索性讨论记录。**

## 性质说明

这里的内容虽然涉及项目技术选型等话题，但本质上是**探索性的、无边界的思维漫游**，不是正式的项目规格说明。

与 `docs/` 文件夹的区别：
- `docs/` = 项目文档（ARCH.md、STATUS.md 等），是开发的可信来源
- `corpus/` = 对话记录和思考痕迹，是图谱的初始语料

## 文件夹结构

```
corpus/
├── README.md           # 本文件
├── EXTRACT_PROMPT.md   # Agent 提炼语料的任务 prompt
└── exploratory/        # 探索性闲聊的话题摘要
    ├── 2026-02-06_哲学工具箱与社会分析实录.md
    └── 2026-02-15_知识管理工具演化与技术选型.md
```

## 使用方式

1. **作为图谱初始数据**：导入 Xenica 后成为知识图谱的种子节点
2. **作为决策追溯**：记录为什么做出某些技术选型（如 SurrealDB → SQLite）
3. **作为 AI 上下文**：Commander/Cursor 等工具可读取此处了解项目背景

## 注意事项

- 此处内容可能包含探索中的想法、被否决的方案、个人思考
- 如需技术规格，请查阅 `docs/ARCH.md`
- 此处不存放个人隐私或敏感信息
