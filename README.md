# Xenica / 织念

**异质信息连接体 —— 非线性认知的图状外化系统**

---

工具不该向思考征收“格式税”。

人的认知本如突触般跳跃、发散，但一旦尝试将思考托付给传统工具，网状的念头便被迫碾成线性文本，自由联想被压进层级目录。表达载体的差异，常常遮蔽了信息内核的同一性；我们在遣词造句和排版上的精力消耗，远大于思考本身。

Xenica 试图终结这种错配。

在底层，一切信息——段落、视频时间轴、代码片段、乃至安全属性——皆被还原为平等的原子节点。在交互层，它顺应大脑自由联想的直觉，让连边代替目录，让拓扑代替层级。我们将工程实现的桎梏隐藏于界面之后，让图谱去承载知识本身。

不为编排而遣词，不为归类而设框。在 Xenica 中，思考保持它本来的形状
