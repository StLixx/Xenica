# v0.2.5 · 开发画板与交付体系

这次发布将真实内容嵌入、草图协作修复和固定开发画板整合到正式主线。

- 固定开发入口：<https://excalidraw.xenica.truebigsand.top/sketch>。画板、原文、图片和批注使用独立持久存储，不随临时预览关闭而删除。
- 从同一工作区打开真实组件和页面；沿用 test 账户，嵌入体验免重复登录，单独打开仍需鉴权，页面不公开密码。
- 草图写回有冲突保护；设计、真实实现、上下文和永久交付记录相互关联。
- 已有镜像和兼容数据快照的历史版本可以按需隔离运行；缺失档案的版本明确标记，最多两个实例，空闲十五分钟释放运行资源。
- 用户在会话定义范围并验收整体体验；工程门禁核验确切产物、规则和最新检查，正式上线推广同一镜像摘要。

此次重点是开发和交付基础设施，知识系统的核心功能未宣称大幅增加。整体体验已验收；UI/UX 的整体设计优化进入下一版。新 Notion 会话验收仍延期。

Git Tag 固定合并后的源码，附件清单同时记录已验收源码和不可变镜像。v0.2.3 的另一份产物尚未定位，不宣称它已包含在本次发布中，也不补造未正式发布的历史 Release。
