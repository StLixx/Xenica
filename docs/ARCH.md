# Xenica 架构文档

**本文档为 Xenica 项目的唯一可信来源**

---

## 一、灵魂

**Xenica / 织念** — 异质信息的智能连接体。

不是笔记工具，不是知识管理，是**大脑的外延**。你不需要"管理"信息，你只需要"使用"信息。

---

## 二、设计哲学

### 认知瞬间是唯一入口
所有信息都是同一种东西：在某个场景下产生的想法或行动冲动。
类型是视角标签（任务/洞察/疑问/素材），不是存储结构。

### 对话即图谱生长
对话不是图谱的输入工具，对话本身就是图谱的生长过程。
每次对话产生局部图谱，自动合并到总图谱。

### 对话后存
AI 讨论/纠正/补充 → 用户确认 → 精炼版存入。
原始认知同时保留，记录认知成长轨迹。

### 全部自动存入
不手动选择存什么。每轮对话实时存入。
废话没关系 — PageRank 让重要的浮上来，不重要的沉底。

### 关联完全自动
AI 自动建立关联 + 分析合并建议。语义/时空/感官三种边。

### 视角标签代替文件夹
同一节点可以同时是多种视角。不同视图 = 不同滤镜。

## 三、界面设计

### 桌面端

```
┌────────────────────────────────┬──────────────┐
│                                  │              │
│         图谱（主区域）           │    对话      │
│   缩放/浏览/点击/实时生长        │    窗口      │
│                                  │   （常驻）   │
│                                  │              │
├────────────────────────────────┴──────────────┤
│ 搜索（命令面板式）| 视图切换 | 待复习 N        │
└───────────────────────────────────────────────┘
```

- 图谱为主，对话在右侧常驻
- 对话中产生的节点实时出现在图谱上
- 底部/侧边可切换视图：图谱 / 时间线 / 列表
- 搜索像 VS Code 命令面板（直接搜节点、加前缀搜内容、呼出命令）

### 手机端

```
底部 Tab：对话 | [快速记录] | 图谱 | 搜索
           中间按钮最大最显眼
```

- 快速记录按钮在底部 Tab 正中间，点击弹出极简模板
- 快速记录模板：想法输入（语音输入法）+ "在做什么"预设标签点选 + 自动时间/定位
- 3 秒保存，不等 AI
- 能连台式机 → 调 AI 完整体验；连不上 → 纯离线记录，回家自动同步
- PWA Service Worker 自动检测连接状态

### 通知中心

入口：铃铛图标。内容分组：
- 待展开：快速记录的碎片，还没和 AI 讨论
- 待复习：间隔重复提醒
- 待确认：AI 自动建立的关联需确认
- Commander 汇报：每日开发日志摘要（台式机开着时）

处理方式：点击处理 / 左滑归档 / 右滑已读

### 节点交互（三种并存）
- 图谱聚焦展开：以节点为中心重排，关联节点靠近
- 浮出详情卡片：小卡片显示摘要
- 面板切换：右侧切为完整节点详情

### 对话设计语言（通用，所有 AI 对话页面复用）
- 用户输入钉在当前轮次顶部（Cursor 风格）
- 对话锚点：右侧边缘一列小圆点，每个圆点 = 一轮对话
- 日常状态：圆点安静地待着，不占空间
- 鼠标悬停圆点区域：展开为摘要文字 + 毛玻璃半透明背景覆盖对话内容
- 点击某个锚点：跳转到那一轮，覆盖层收起
- 手机端：顶部下拉式轮次导航（屏幕太小放不下侧边圆点）

### 配色方案
三种主题全部保留，可切换：
- 方案 A 琥珀暖光（默认）
- 方案 B 靛蓝墨水
- 方案 C 橄榄森林
深色 + 浅色双模式

## 四、功能模块

### 对话引擎
- 多对话同时进行（各自独立，共享图谱）
- AI 记忆策略可配置：按需调取（默认）/ 手动指定 / 记住所有（未来 token 便宜后）
- 每轮自动存入图谱，实时生长

### 图谱引擎
- 联想链检索（沿边遍历）
- 语义搜索（向量匹配）
- 多视图：力导向图 / 时间线 / 列表 / 目标树
- PageRank 式重要性浮沉

### 间隔重复（三种模式）
- 打开时提醒：外部任务（老师布置的背诵）
- 融入对话：AI 自然提到"你之前记的 XX 还记得吗"
- 独立模块：刷题/考试场景的卡片翻转

### 输出生成
- 对话中说"帮我整理成文章"
- 图谱中选节点 → 生成
- 自己先写草稿，AI 陪着深化

### 输入适配
- 文字（直接对话）
- 拍照 OCR（错题/手写笔记）
- 语音转文字
- 视频链接（通义听悟/Gemini 转文稿）
- 导入已有数据（Obsidian/Cursor 对话记录）

### 主动服务
- 间隔重复提醒
- 目标对齐（当前做的事对长远目标有没有用）
- AI 爬取可能有用的外部信息

## 五、节点结构

| 属性 | 说明 | 必须 |
|------|------|------|
| raw_input | 用户原话 | 是 |
| refined | 精炼表述 | 否 |
| trigger | 触发源/场景 | 否 |
| timestamp | 时间 | 是 |
| location | 地点 | 否 |
| perspectives | 视角标签（多个） | 否 |
| embedding | 语义向量 | 自动 |
| conversation_id | 属于哪次对话 | 是 |

### 边类型
- semantic：概念相关
- temporal：同时/同地
- sensory：感官触发
- evolution：认知演化（朴素 → 精炼）

### 实体
从认知瞬间提取的可复用知识点。附着在认知瞬间上。

## 六、技术栈

| 组件 | 选型 |
|------|------|
| 后端 | Rust + Axum |
| 数据库 | SurrealDB（嵌入式，RocksDB） |
| 前端 | React + TypeScript + TailwindCSS + react-flow |
| LLM | Claude Opus（对话）/ Sonnet（提取）/ Gemini Flash（廉价） |

| 部署 | 台式机常开（32GB + 1TB SSD + 4TB HDD + UPS） |
| 远程 | Cloudflare Tunnel |

## 七、系统架构

```
用户（文字/语音/拍照/链接）
    ↓
输入适配层
    ↓
对话引擎（Claude Opus）
    ↓ 每轮实时存入
局部图谱（本次对话的节点和边）
    ↓ 自动合并
总图谱（SurrealDB）
    ↓
图谱引擎
    ├── 联想链（沿边遍历）
    ├── 语义搜索（向量）
    ├── PageRank（重要性）
    └── 多视图渲染（react-flow）
    ↓
主动服务
    ├── 间隔重复
    ├── 目标对齐
    └── 输出生成
```

## 十二、交互细节

### 图谱实时生长
AI 每回复完一轮，后台提取新节点，延迟 2-3 秒以动画出现在图谱上。
位置由关联度决定（和最强关联的已有节点相邻）。不是实时逐字加。

### 局部图谱合并策略
- 实体（人物/概念/作品）：去重，已有则连边不重复创建
- 认知瞬间：每次都是新的，不去重
- 冲突（旧观点 vs 新观点）：两个都保留，用演化边连接

### 目标体系
- 首次启动 AI 引导创建 3-5 个长期目标
- 之后从对话中自动提取短期目标
- AI 对话时自动判断"当前话题和哪个目标相关"

## 十三、安全与备份

### 密码
简单固定密码（配置文件，不进 git）。Session 24 小时。

### 自动备份
每日凌晨：打包 SurrealDB 数据 → 复制到 OneDrive 同步目录。
保留 30 天每日备份 + 每月永久备份。

单向流入：Commander 开发日志 → 自动存入 Xenica 图谱。
Xenica 任务 → 不自动发给 Commander（手动确认后才发）。
