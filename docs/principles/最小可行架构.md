# 最小可行架构

给接下来要降落的那架飞机铺够跑道，别建整条机场。

在动手写代码之前，架构只设计到刚好能支撑下一个 Phase 的功能落地，不预测更远的需求。超过了就是过度设计——预测十有八九是错的，错误的预测比不做预测更糟。

## 具体场景

问自己：现在要做的这几个场景，跑通它最少需要哪几个组件？它们之间用什么接口？数据怎么存？只回答这几个问题，不画五年蓝图。
