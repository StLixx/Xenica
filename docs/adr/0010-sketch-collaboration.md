# 草图协作：条件写与正式档案

Notion 实测确认旧编辑器会覆盖 AI 写回；临时 PR 数据库也不能承担长期设计记忆。

写入以读到的 `updated_at` 为版本。浏览器 PATCH 用 `If-Match`，分享 PUT 用 `expected_revision`；Store 在同一行锁事务中检查、保存旧画面的完整快照、写入新画面。旧版本或缺少版本返回 409，不自动覆盖或猜测合并。空闲画面轮询更新，有本地改动时保留双方，由用户另存草稿后比较。

正式草图站保存设计说明、场景、真实截图与历史。预览仅验证指定 commit；搬迁使用可校验的档案，包含原图和历史，不包含分享凭据。导入只创建，不覆盖目标同 ID 草图，不自动修改正式表结构。导入动作走 Store 并记录痕迹；旧站也能保存档案，升级后提供完整分享上下文。

结构 PNG 和真实内容截图分开；AI 写回后旧 PNG 标为 previous，当前标为 missing。真实截图记录元素、来源、版本、像素尺寸与 commit；无法核实的视口明确标记，不伪装成自动截图。外部网页不承诺可截图，样例输入不升级为持久设计状态。

链接只读和授权写入分开。摘要是用户数据，不能作为 Agent 指令。Notion 是否有写工具需在新会话验证；本轮用户决定先修接口，后做 Notion 验收。
