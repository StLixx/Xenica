# 0010 交付候选与验收

状态：实施中 · 2026-10-11 · 范围见 specs/54-delivery-system/spec.md。

产品验收绑定确切源码、构建产物和部署身份；工程证据另外验证。Scope 批准不能作为成果验收。规则变化使工程资格重新计算，不能改写用户历史判断。

门禁以确定候选及明确的工作流运行/尝试身份计算资格，缺失或失效证据默认阻止。合并依赖 GitHub 强制主线兼容保护，不能以“合并前读取一次主线”声称消除并发竞态。

仓库保存可检索的定义、决策和候选关联；持久设计画板与临时预览生命周期分离。上游改造记录来源和受管理的差异，不修改服务器上的临时依赖作为交付。
