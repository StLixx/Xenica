# 0018 GitHub 长期事实源与远程开发

状态：已确认 · 2026-10-16 · 任务 #74；开发脚手架收尾，沿用 v0.2.5。

## 决策

GitHub 仓库 `StLixx/Xenica` 是项目唯一长期事实源。Infra、core、其他部署服务器及软件实例都可重建；会话和本机记忆只帮助检索，不能代替仓库中的已确认记录。

源码、用户决定、Agent 职责、部署维护经验、后续任务与可公开案例应进入同一仓库，并区分决定、现场事实、历史和待验证项。实际采用的设计源文件与未来自托管管理工具的可公开资料也须版本化，保留可编辑原件、关联素材和导入方式；截图或服务器数据库不能单独承担这一职责。隐私与密钥另行私有备份，公开仓库暂时少人访问不构成放宽边界的理由。这补充了 ADR 0017 的原稿边界：正式采用且可公开的设计入 Git，隐私原件继续私有。

Windows 只保留聊天、SSH、浏览器与轻量入口；阅读、修改源码、构建和测试均在 Infra 的独立 Git 工作区完成。新会话先确认主机、仓库远端、提交和未提交状态，再读远程 `AGENTS.md` 与接续索引。旧同步目录不是默认开发入口；Infra 不可用时报告阻碍。

## 范围

v0.2.5 收尾负责质检、部署与开发脚手架，结束临时体验式开发。当前 Penpot 的 Design Token 和页面均为测试 Draft，不作为需归档的正式设计，本任务不操作其在线内容；新设计和产品优化放到下一版本，工具选型由另一会话负责。

执行核对与恢复入口见 `docs/context/remote-development.md`；本地资料只有在远端恢复校验通过后才清理。
