# 0021：以现版 XMind 为编辑行为基准
2026-10-17。用户试过现有导图替代内核，明确要求复刻现版 XMind；Web/桌面按逆向便利性选择。开始授权已完成，交互成果仍需最终体验验收。

先从 Web 的实际编辑器入口和发布资源审计原生编辑、布局及服务依赖。优先验证是否能保留原生内核并用独立数据/宿主适配，未经证据不承诺解包即部署。官方旧 viewer 只能作为研究候选；不直接用旧只读渲染器替代当前完整编辑器。任何复用须记录来源与许可边界，第三方闭源发布资产保留私有研究副本，不作为 Xenica 开源源码上传。

固定入口 xmind.truebigsand.top，Infra 开发与服务运行，hikari 仅承接现有 HTTPS 网关方式。保留实体与视图分离接入位置，先实现已审核的原生核心体验和独立保存，不扩展到全面 Xenica 内容迁移。

已验证决定：保留同版 Snowmonster 编辑、布局与 DocumentKit，重建外围宿主，不加载会自动启动官方云应用的 app.entry。快照以 schema:1 包装原生 content/metadata 和资源字节，主题 ID 保持原生身份；这层适配是未来实体/视图拆分的位置，当前不把一个 XMind topic 冒充已迁入 Xenica 的实体。

独立试用实例不写 Xenica 领域库：SQLite 的乐观版本事务同时写当前图和不可变历史，专用用户及域名隔离。UI 暂按原版默认浅色及 NeverMind 字体复现，此入口独立于 Xenica 暗色工作台。第三方发布文件不入公开 Git，冻结清单、来源和私有恢复方式随宿主提交。用户体验验收通过前仍保持草稿，不合并。
