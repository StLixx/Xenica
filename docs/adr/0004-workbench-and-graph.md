# 0004 工作台与图

状态：已采纳 · 2026-10

## 决定

- 界面是 VS Code / Obsidian 式的工作台：侧栏 + 可拆分、可停靠的标签页面板（dockview）+ 命令面板（Ctrl K）+ 状态栏。布局存在本地。
- **图是导航，不是编辑画布。** 在图上找、跳、看关系；阅读和编辑在面板里打开节点完成。
- 图自动布局，不手动拖位置：整体结构参考 XMind 的树状展开，聚焦参考 TheBrain（选中节点居中，显示它的邻居，其余淡出）。缩放时按层级省略细节。
- 块就是节点（Notion 式）：PDF 拆出的每个段落、公式、图都是节点，可以拖进图里、互相关联。
- 只做暗色。

## 理由

- 手动摆位置的成本随节点数增长，节点一多就没法维护。自动布局 + 聚焦让图在任何规模下都可用。
- 阅读和编辑需要大面积文本区，面板比画布上的小卡片合适；多个面板并排可以同时看原文和笔记。

## 后果

- 「位置」原语只存视图的偏好（展开/折叠、聚焦历史），不存手摆坐标。
- 骨架里的图视图是环形占位布局，后续替换为真正的自动布局。
