# 0021：AFFiNE MCP 原生创作扩展

2026-10-17。用户确认原生块、图片/附件、数据库、原生导图/白板及资料整理范围并回复「开始」。保留 AFFiNE 0.27.4、固定所有者/工作区与既有 `/rw-mcp` OAuth 入口；最终交互验收独立进行。

第三方 `DAWNCR0W/affine-mcp-server` 固定 `a4cc2ef87684b46326b406d572b8c2ef09f3f2ca`（MIT，3.9.1），以库加载原生同步实现，SDK 内存传输负责工具输入/输出校验。新增独立适配服务，许可清单仅开放 57 项原生创作/读取工具；已有 6 项工具沿用原桥接。第三方 HTTP/OAuth/管理工具不作为部署入口，永久删除、公开发布和账号管理不开放。

隔离 0.27.4 实测发现并以可复现补丁修复数字列缺少原生 `data` 默认值、中文导图宽度估算不足、折叠未持久化后代形状隐藏状态。附件使用内容摘要作为存储文件名，避免上游按文件名存储时覆盖同名附件。读取图片先确认文档仍在授权工作区，再解析原生图片块，限量读取固定上游附件并返回 MCP image 内容；拒绝任意 URL、跨文档块与非图片格式。

原生文档内容变更要求最新 `read_doc.revision` / `expectedRevision`，原工具继续使用 `read_document` / `expected_revision`。原生写入持久化客户端独立的幂等意图和结果；未知结果不再执行，要求回读核对。网关单进程串行转发旧/新后端请求，原生后端再按工作区协调；不声称能锁住网页或其他进程，也不声称上游具备原子 CAS。元数据、多文档和组合操作不假装事务。

原生导图仍是文字形状节点；图片是独立原生图片块，不能宣称会随导图层级折叠或自动布局。工具返回图像像素与两个客户端能否识图分开验收。新适配状态加入既有加密、异地主机/云端备份和隔离完整性检查。详细构建、升级/回退与证据见 `deploy/affine-rw-mcp/authoring/`。
