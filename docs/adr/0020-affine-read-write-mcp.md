# 0020：AFFiNE 稳定版外置读写 MCP

2026-10-17。用户重新授权读写接入，要求先 ChatGPT Plugin / Chat，后 Notion AI，不打断另一会话的稳定部署收尾。源码可放 AFFiNE Fork；部署、维护、决定与证据仍归 Xenica。开始授权不等于交互成果验收。

采用独立同步适配器，固定 AFFiNE 0.27.4 原生转换器与认证工作区同步协议，开放列表、中文搜索、读取、新建、修改简单 Markdown 正文、修改标题。稳定应用、数据库、Copilot/索引开关和已有凭据不变；不全局伪装 dev/canary。实现位于用户 Fork 的独立目录，避免把庞大上游源码复制进 Xenica。

外部客户端通过独立 OAuth 2.1 / S256 PKCE 网关获得申请的权限；浏览器现有 AFFiNE 登录校验固定所有者与工作区。上游密码和内部桥接凭据仅留私有配置，客户端 Bearer 不传给 AFFiNE。只读授权不能调用写入；授权码和刷新令牌一次使用，访问令牌一小时，连接最长三十天，支持撤销。ChatGPT 和 Notion 使用各自独立的授权记录。

写入要求回读版本和持久化幂等键，提交原生 CRDT 差异并核验结果。复杂块与有内容的白板拒绝正文替换，不提供删除工具。现有同步协议没有原子比较并写入，同一段落的同时编辑仍受 Yjs 合并语义影响，不能承诺数据库事务级乐观锁；工具应在冲突后重新读取而不是盲目覆盖。搜索为有上限的实时扫描，不依赖这次未部署的全文索引。

独立服务支持重启恢复、在线 SQLite 快照、配置加密异地备份和只读健康检查；AFFiNE 数据库与附件继续由原稳定版保护链负责。操作、边界、真实客户端验收与精确身份见 [维护入口](../context/affine-rw-mcp.md) 和 [部署手册](../../deploy/affine-rw-mcp/README.md)。#76 中 MCP 搁置的调查保留为历史，不能再当作这次读写接入的当前状态。
