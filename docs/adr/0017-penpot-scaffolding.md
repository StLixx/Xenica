# 0017 Penpot 设计脚手架与接续记录

状态：已采纳 · 2026-10-14 · 父任务 #54，任务 #65，体验版本关联 v0.2.5。

## 决定

Penpot 作为独立的自用设计服务，固定公网入口，经 hikari 到 Infra；文件使用 Infra 的 `/mnt/HDD`，数据库使用共享 PG 的专用数据库和角色。官方 MCP 接入个人 ChatGPT，开放原生 API Token、Webhooks 和管理入口；Xenica 内嵌和事件接收留给后续任务。

部署配置与运维代码保存在本仓库；接续从 `docs/context/index.json` 进入设备清单、操作入口和证据。用户决定、当前实测、历史记录和未验证事项分别记录；密码、私钥、MCP 连接密钥、个人邮箱与设计原件保留在私有存储。

用户明确要求把长期信息提交并合并，归入 v0.2.5 开发脚手架搭建目标。此次是 2026-10-14 的发布后追加任务；已发布 v0.2.5 的不可变 Tag、附件及原发布产物保持原身份。

## 理由与后果

同一任务链可以追查部署选择、端口漂移、监控漏检、素材下载修复及恢复证据，后续 Agent 复用现有实例和 PR，避免重新猜测设备或清理用户已采用的验证文件。

原版升级须复核固定镜像、图片请求标识覆盖和推广样式选择器。数据库与文件按一致时点每日备份，恢复演练独立于生产；整机丢失、跨版本恢复、SMTP 和 Xenica 内嵌均不登记为已验证。
