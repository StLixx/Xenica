# 0021：Penpot 画板内 HTML 嵌入试样

状态：2026-10-17 用户批准试作，体验待验收。关联 #81。

用户需要可保存、可移动缩放的画板内交互块，插件悬浮窗口不满足。参考 Excalidraw 的场景元素与 DOM iframe 层，在当前 Penpot 稳定基线加入受限扩展。普通矩形承载位置尺寸，命名空间 plugin-data 保存内容和显式状态；iframe 跟随画布坐标，进入交互后接收鼠标键盘。保留原生文件、撤销及权限机制，不新增数据库类型。

固定源码与已有多会话补丁共同构建前端，保留旧镜像和恢复入口。自检通过后交用户体验，确认前不合并；不把视频概念验证或整个 develop 当作稳定依赖。
